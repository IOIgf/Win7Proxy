# Win7Proxy — Windows 7 代理客户端

一个能在 **Windows 7 SP1 (x64)** 上运行的代理客户端，基于 **Xray-core（官方 `-win7` 构建）**，
支持导入 **v2rayN / Clash / SIP008** 三种订阅，覆盖 VMess、VLESS(+XTLS/REALITY)、Trojan、
Shadowsocks/SS2022、Socks、HTTP 等主流协议。流量接管方式为 **系统代理 + Xray 路由分流**（无驱动、无 TUN）：
系统代理指向本机 Xray 端口，由 Xray 按 geoip/geosite 规则把国内/私有网段直连、其余走代理。

当前版本：**v1.1.0**

## 一、前置条件（一次性的）

1. **Windows 7 SP1 x64**。
2. 安装 **.NET Framework 4.6.1 及以上**（本项目编译目标为 `net461`，已装的 4.6.1 可直接运行；
   Win7 最高支持到 **4.8**，**4.8.1 起仅支持 Win10/11**，请勿在 Win7 上装 4.8.1）。
   若尚无任何 .NET Framework，到 https://dotnet.microsoft.com/download/dotnet-framework/net48
   下载 4.8 离线安装包（Win7 可用）。
3. 建议安装 Windows 更新补丁 **KB4474419 / KB4490628**（让老系统正确支持 TLS 1.2，
   否则 https 订阅可能拉取失败）。

## 二、首次运行

1. 解压 `Win7Proxy-v1.1.1.zip` 到任意目录（路径不要含中文/空格最佳）。
2. 内核已随包提供：`core\xray.exe` 与 `core\geoip.dat` / `core\geosite.dat` 解压即用。
   仅当要**更新**内核时，再运行 `fetch-core.bat` 拉取最新 xray-win7（内置多个 GitHub 镜像，逐个尝试）。
3. 双击 `Win7Proxy.exe`。

## 三、使用

- **导入订阅**：工具栏「导入订阅」或菜单「订阅 → 导入订阅」→ 填写订阅 URL 与名称 → 拉取。支持：
  - v2rayN 订阅（base64 包裹的 vmess/vless/trojan/ss 链接）
  - Clash / mihomo 订阅（YAML `proxies:` 列表，含 `reality-opts` / `grpc-opts` / `h2-opts`）
  - SIP008（Shadowsocks 官方 JSON）
  - 格式可自动识别，也可在对话框里手动指定。
  - 若订阅站点使用自签名证书，勾选「跳过 TLS 证书校验」。**该项只对这一次请求生效**，
    程序默认严格校验证书，不会全局关闭验证。
  - **重复导入同一个 URL 会替换旧订阅的节点**，不会越积越多。
- **从剪贴板导入**：菜单「订阅 → 从剪贴板导入」，单条链接或整份订阅文本都可以。
- **更新订阅**：工具栏「更新订阅」会重新拉取所有订阅；「订阅 → 订阅管理」可单独
  更新 / 编辑 / 删除某个订阅（删除订阅会连带删除它带来的节点）。更新时会尽量把已测得的延迟继承下来。
- **添加节点**：菜单「节点 → 添加节点」，粘贴单条 `vmess://` / `vless://` / `trojan://` / `ss://` 链接。
- **复制原始链接**：选中节点后「节点 → 复制原始链接」，把分享链接放回剪贴板。
- **去重 / 清空延迟**：菜单「节点 → 去除重复节点 / 清空延迟结果」。
- **测试延迟**：在节点列表里**按住 Ctrl 逐个点选、或 Shift 框选**多个节点，再点「测试延迟」即可批量测延迟
  （点「全选」可一键选中全部；不选任何行则测全部）。最多 16 并发，按 `Address:Port` 的 TCP 连通性计时。
  注意这是**到节点服务器的 TCP 往返时延**，不是"打开网页的体感速度"，只适合用来横向比较节点。
- **批量删除**：选中多个节点后点「删除选中」可一次移除（会二次确认）。
- **按列排序**：点击表头按该列排序（再点一次切换升/降序）。延迟列按数值排序，
  未测（`-`）的排到最后。刷新列表会保持滚动位置和选中项。
- **选择节点 + 启动**：单击选中一个节点（上方「当前节点」会显示是谁），选好模式后点「启动」；
  **双击某一行可直接以该节点启动**；换节点就选另一个再点「启动」（会先停旧内核再起新的）。
  - 模式「全局」：所有流量走代理。
  - 模式「规则」：国内/私有网段直连，其余走代理（geoip/geosite 自动分流，无需 PAC 文件）。
    规则模式下额外配置国内 DNS，避免域名被污染成境外 IP 后误判为需要代理。
  - 模式「直连」：关闭系统代理，**不启动内核**。
  - **运行中切换模式会立即重建配置并重启内核**，不用再手动点一次「启动」。
- **停止**：点「停止」结束 xray 并恢复系统代理为「不使用代理」。
  内核若自行崩溃退出，程序也会自动撤掉系统代理，不会让你卡在"代理开着但没人干活"的断网状态。
- **托盘**：右下角托盘图标可「启动 / 停止 / 显示窗口 / 退出」。
- **设置**：菜单「设置」里可开启**开机自动启动**、**启动时自动连接上次节点**、**导入订阅时自动去重**。
- **更新内核**：工具栏「更新内核」运行 `fetch-core.bat`（内置 5 个镜像源依次兜底）。

## 四、配置文件

- 订阅与节点、当前选择、模式与偏好设置保存在 `%AppData%\Win7Proxy\app.json`，随时自动保存。
- 运行期生成的 xray 配置在 `core\config.json`，日志在 `core\access.log` / `core\error.log`。
- 内核进程 PID 记录在 `core\xray.pid`，用于清理上次异常退出残留的进程。

## 五、排错

- **启动报“找不到 xray.exe”**：按第二节放置内核，或运行 `fetch-core.bat`。
- **订阅拉取失败 / TLS 错误**：安装 KB4474419/KB4490628；若站点是自签名证书，
  在导入对话框勾选「跳过 TLS 证书校验」。
- **系统代理未生效**：确认浏览器使用“使用系统代理”。修改模式或节点后建议重启浏览器，
  让它重新读取系统代理设置。
- **端口被占用**：若启动时日志提示 10808 端口已被占用，说明有另一个代理软件在跑，
  先退出它再启动。
- **无法访问内网/局域网**：私有网段默认直连（同时写进了系统代理的绕过列表），一般无需处理。

## 六、从源码构建（开发者）

在 Windows 上用 Visual Studio 2019/2022 打开 `Win7Proxy.sln` 直接生成即可。
也可用 .NET 8 SDK 编译（编译目标为 `net461`，兼容 Win7 的 .NET 4.6.1+）：

```
dotnet build Win7Proxy/Win7Proxy.csproj -c Release -f net461
```

（需 `Microsoft.NETFramework.ReferenceAssemblies.net461` 提供 net461 引用程序集；
`ProxyCore` 同时多目标 `net461;net8.0`，被 GUI 引用时取 net461。）

逻辑层 `ProxyCore` 的单元测试：

```
dotnet test ProxyCore.Tests/ProxyCore.Tests.csproj
```

Linux/macOS 上可用 `./pack.sh [版本号]` 构建并打包（脚本假定 .NET SDK 在 `./.dotnet/dotnet`）。

### 自动构建与发布

仓库已配置 GitHub Actions（`.github/workflows/build.yml`）：推送 `main`、发起 PR 或手动触发时，
会先跑单元测试，再在 Linux runner 上构建 `net461` Release，下载 xray-win7 内核与 geo 数据
（多镜像兜底），打包成 `Win7Proxy-<版本号>.zip` 上传为构件；
打 `v*` 标签（如 `v1.1.0`）推送时，会自动创建 GitHub Release 并附上该 zip。

## 七、版本记录

### v1.1.1

修复：

- **高 DPI 下界面发虚（Win10/11 上尤其明显）**：程序原先没有 Win32 清单，进程是 DPI 无感知的，
  Windows 会把整个窗口当位图放大后交给程序绘制 —— 在 150% 缩放下相当于把 860×600 的画面
  硬拉成 1290×900，必然发糊。现已补齐 `app.manifest`（声明 Per-Monitor v2，Win7 上自动降级为
  系统级感知，不影响兼容性），并按屏幕 DPI 显式放大控件尺寸，避免"字体变大但按钮没变大"的错位。
  实测：150% 缩放下进程 DPI 感知状态由 `UNAWARE`（窗口 DPI 恒报 96）变为
  `PER-MONITOR AWARE`（正确识别 144），窗口由系统拉伸改为程序按 1290×900 原生绘制。

### v1.1.0

修复：

- **安全**：移除全局关闭 TLS 证书校验的行为（旧版会让订阅内容和节点凭据暴露给中间人），
  改为默认严格校验，仅在用户勾选时对单次请求放宽；同时停用已淘汰的 TLS 1.1。
- **直连模式不再空转内核**：旧版选「直连」仍会启动 xray，随后又把系统代理清掉。
- **运行中切换模式立即生效**：旧版只存盘不重启内核，切了模式其实没变。
- **vmess 节点不再被静默丢弃**：订阅里 `"tls": true`（布尔值）会让旧版解析抛异常，
  节点无声消失。
- **传输层协议名归一化**：`websocket` / `http` / `gun` 等别名统一成 xray 认识的
  `ws` / `h2` / `grpc`。
- **Clash 订阅支持 REALITY / gRPC / h2**：旧版读不到 `reality-opts`、`grpc-opts`、
  `h2-opts`、`skip-cert-verify`，这类节点会生成残缺配置。
- **重复导入订阅不再无限追加节点**。
- **内核崩溃时自动撤掉系统代理**，避免断网。
- 打包脚本：修正 `pack.sh` 里的目标框架（net48 → net461）和不存在的 `fetch-core.ps1` 引用；
  CI 产物名不再固定写成 v1.0。

新增：

- 订阅管理（更新 / 编辑 / 删除单个订阅）、批量更新订阅
- 从剪贴板导入、复制节点原始链接、节点去重、清空延迟
- 开机自启、启动时自动连接、导入时自动去重
- 入站嗅探（sniffing）、规则模式国内 DNS、系统代理绕过列表、内核版本显示
- 残留内核进程清理（PID 文件）、端口占用预警
